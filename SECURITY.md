# Security Policy · سياسة الأمان

## Reporting a vulnerability

Please do **not** open a public issue. Report privately through
[GitHub's private vulnerability reporting](https://github.com/helalrules7/tibyan/security/advisories/new)
or by email to **info@altibyan.app**.

Include what is affected (app version and platform, altibyan.app, train.altibyan.app),
steps to reproduce, and the impact. We reply within 7 days.

للإبلاغ عن ثغرة: لا تفتح مشكلة عامة، وراسلنا على info@altibyan.app أو عبر الإبلاغ الخاص في GitHub.

## Supported versions

Only the latest release and `main` receive fixes.

## Scope

- The Tibyan app (all platforms), [altibyan.app](https://altibyan.app) and [train.altibyan.app](https://train.altibyan.app).
- Errors in Quran text or scholarly content are not security issues: open an issue so they are checked against the source.
