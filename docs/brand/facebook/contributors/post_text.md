## العربية

ساهم في بناء «تبيان» 🤍

تبيان تطبيق قرآن مجاني بالكامل، غير ربحي، بلا إعلانات ولا تتبع. وكوده كله مفتوح على GitHub بترخيص GPL-3.0.

مبني بـ Flutter/Dart على أندرويد وiOS وmacOS، ومعه منصة تدريب بـ FastAPI، وتسميع يعمل على جهازك نفسه (sherpa-onnx) فلا يغادره صوتك.

ولنا قاعدة لا نتنازل عنها: لا محتوى دينيًا مولّدًا بالذكاء الاصطناعي. كل نص منقول حرفيًا من مصدره، وكل مصدر منسوب لأهله.

مكانك محجوز، أيًّا كانت مهارتك:
• برمجة: Flutter وDart وPython/FastAPI
• تصميم وتجربة استخدام
• اختبار التطبيق والإبلاغ عن الأخطاء
• الترجمة
• مراجعة المحتوى على مصادره
• سجّل تلاوتك لتدريب نموذج التسميع: https://train.altibyan.app (تُنشر بترخيص CC BY 4.0)
• أو انشر الخبر، فهذه مساهمة أيضًا

## English

Help build Tibyan, a free, non-profit Quran app with no ads and no tracking.

The code is open on GitHub under GPL-3.0: Flutter/Dart for Android, iOS and macOS, a FastAPI training platform, and on-device speech recognition (sherpa-onnx). One firm rule: no AI-generated religious content. Every source is credited.

Ways to help: code (Flutter, Dart, Python/FastAPI), design/UX, testing and bug reports, translations, checking content against its sources, recording your voice at https://train.altibyan.app (CC BY 4.0), or simply sharing this post.

Start here: https://github.com/helalrules7/tibyan (read CONTRIBUTING.md first)
Beta: https://altibyan.app/beta
