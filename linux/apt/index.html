مستودع تبيان لأنظمة ديبيان وأوبونتو

لأوبونتو 22.04 فما بعده، وديبيان 12 فما بعده، على معالجات amd64.

التثبيت بأمر واحد

curl -fsSL https://apt.altibyan.app/setup.sh | sudo sh
sudo apt install tibyan

يضيف setup.sh مفتاح المستودع ومصدره ثم يحدّث قوائم الحزم. اقرأه قبل تشغيله إن شئت، فهو قصير.

التثبيت يدويا

sudo curl -fsSL https://apt.altibyan.app/tibyan.gpg -o /usr/share/keyrings/tibyan.gpg
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/tibyan.gpg] https://apt.altibyan.app stable main" \
  | sudo tee /etc/apt/sources.list.d/tibyan.list
sudo apt update
sudo apt install tibyan

بصمة مفتاح التوقيع:

FC13 3403 7A6C B01E B36B  C6ED 38F7 5171 F3BC 0B1B

التحديث والإزالة

تصل الإصدارات الجديدة مع sudo apt upgrade. وللإزالة:

sudo apt remove tibyan
sudo rm /etc/apt/sources.list.d/tibyan.list /usr/share/keyrings/tibyan.gpg

ولسائر التوزيعات ملف AppImage في صفحة الإصدارات. الموقع: altibyan.app.

Tibyan APT repository

For Ubuntu 22.04 or newer and Debian 12 or newer, on amd64.

One-command setup

curl -fsSL https://apt.altibyan.app/setup.sh | sudo sh
sudo apt install tibyan

setup.sh adds the repository key and source, then refreshes the package lists. It is short; read it first if you like.

Manual setup

sudo curl -fsSL https://apt.altibyan.app/tibyan.gpg -o /usr/share/keyrings/tibyan.gpg
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/tibyan.gpg] https://apt.altibyan.app stable main" \
  | sudo tee /etc/apt/sources.list.d/tibyan.list
sudo apt update
sudo apt install tibyan

Signing key fingerprint:

FC13 3403 7A6C B01E B36B  C6ED 38F7 5171 F3BC 0B1B

Updates and removal

New versions arrive with sudo apt upgrade. To remove:

sudo apt remove tibyan
sudo rm /etc/apt/sources.list.d/tibyan.list /usr/share/keyrings/tibyan.gpg

For other distributions, an AppImage is on the releases page. Website: altibyan.app.
